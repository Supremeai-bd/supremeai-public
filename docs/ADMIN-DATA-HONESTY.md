# Admin কনসোল — ডেটা-উৎসের সত্যতা (Audit + Fix)

**তারিখ:** ২০২৬-১১-২৩ · **স্কোপ:** `src/components/admin/` (৩৭টি ফাইল), `src/services/adminService.ts`, `src/data/`

---

## ০. কেন এই কাজ

প্ল্যান ছিল "admin ভিউতে DEMO ব্যাজ বসানো"। কিন্তু অডিট করতে গিয়ে দেখা গেল
সমস্যাটা ব্যাজের নয় — **ভিউগুলো নিজেরাই মিথ্যা দাবি করছিল**, হার্ডকোড করা টেক্সট দিয়ে।

দুটো নির্দিষ্ট উদাহরণ (`AdminFeatureFlagsView.tsx`):

```
"Platform Config · Server Enforced"      ← কোনো যাচাই ছাড়া লেখা
"Live Server Sync Active"                 ← কোনো যাচাই ছাড়া লেখা
```

আর একটি টোস্ট মেসেজ:

```
"Feature Flag \"X\" has been ENABLED server-wide."
```

**এটা মিথ্যা ছিল।** প্রমাণ নিচে।

---

## ১. প্রমাণ — "server-wide" আসলে কিছুই করত না

কোডবেসজুড়ে grep করে দেখা গেল `config.featureFlags` **মাত্র একটি** জায়গায় পড়া হয়:

| ফাইল | লাইন | কী পড়ে |
| --- | --- | --- |
| `src/components/ChatInput.tsx` | ১৪২ | `config.featureFlags.enable_multimodal_vision` |

আর কোনো ফিচার নেই যা ফ্ল্যাগ দিয়ে গেট হয়। মানে ২৫টি ফ্ল্যাগের মধ্যে **একটি** বাস্তবে কাজ করে;
বাকি ২৪টি শুধু সঞ্চিত হয়।

## ২. দ্বিতীয় সমস্যা — পড়া আর লেখা ভিন্ন জায়গা

| পথ | কোথা থেকে |
| --- | --- |
| **পড়া** | `INITIAL_FEATURE_FLAGS` (`src/data/adminExpansionData.ts`) + `DEFAULT_CONFIG` |
| **লেখা** | `POST /api/v1/admin/feature-flags` (`adminService.ts:202`) |

অর্থাৎ টগল করলে সার্ভারে যায়, কিন্তু তালিকা ও অবস্থা দেখানো হয় স্ট্যাটিক ডেটা থেকে।
ব্যবহারকারী ভাবেন ফ্ল্যাগ "সার্ভার-ওয়াইড" বদলেছে — আসলে UI যা দেখায় তা অন্য উৎস।

## ৩. তৃতীয় — ফলব্যাক নিঃশব্দ

`adminService`-এর ৪৪টি async মেথডের মধ্যে **২৪টি** `INITIAL_*` স্ট্যাটিক ডেটায় ফলব্যাক করে।
আগে ব্যবহারকারীকে জানানোর কোনো উপায় ছিল না যে সে ডেমো দেখছে।

## ৪. যা ঠিক করা হয়েছে

### ৪.১ `DataSourceBadge` — নতুন shared primitive

`src/components/common/DataSourceBadge.tsx`

| অবস্থা | রঙ | অর্থ |
| --- | --- | --- |
| `LIVE` | সবুজ | লাইভ সার্ভার API থেকে |
| `DEMO` | হলুদ | `src/data/*`-এর স্ট্যাটিক নমুনা |
| `DEGRADED` | কমলা | API ব্যর্থ বা ডেটা পুরনো |
| `UNKNOWN` | ধূসর | এখনো নির্ধারিত হয়নি |

`reason` **বাধ্যতামূলক** — ব্যাজ কখনো ব্যাখ্যা ছাড়া দেখানো যায় না। `ageMs` দিলে
"1m আগে" দেখায়, কিন্তু **অবৈধ মানে (ঋণাত্মক/NaN) কিছুই দেখায় না** — ভুয়া সংখ্যা নয়।

### ৪.২ `useDataSource` hook — ভিউ নিজেই সত্য বলে

`src/hooks/useDataSource.ts`

তিনটে আলাদা সত্য মিলিয়ে অবস্থা ঠিক করে: মক মোড, অনুরোধের সাফল্য, ডেটার বয়স।
আগে এগুলোর কোনোটাই দৃশ্যমান ছিল না।

### ৪.৩ ফ্ল্যাগের সত্য — এখন কোড থেকেই মাপা হয়

> **হালনাগাদ (২০২৬-১১-২৭):** আগের হাতে-লেখা `src/data/featureFlagConsumers.ts` তালিকা
> সরানো হয়েছে — feature-flags ট্যাব মুছে যাওয়ার পর ফাইলটা কোথাও import হত না
> (নিজেই ডেড কোড ছিল)। Admin Overview এখন শুধু সেই ফ্ল্যাগ দেখায় যেগুলো সত্যিই
> রানটাইমে পড়া হয় (`INITIAL_FEATURE_FLAGS`: `enable_multimodal_vision`,
> `enable_rag_grounding`)। `src/data/featureFlags.test.ts` সোর্স স্ক্যান করে যাচাই
> করে যে প্রতিটি দেখানো ফ্ল্যাগ অন্তত একবার `featureFlags.<key>` /
> `runtimeFeatureFlags.<key>` হিসেবে পড়া হয় — ডেড ফ্ল্যাগ যোগ করলে CI লাল হবে।

### ৪.৪ `AdminFeatureFlagsView` আপডেট (ঐতিহাসিক — ট্যাবটি PR #122-এ মুছে Admin Overview-এ একীভূত)

- হার্ডকোড `"Server Enforced"` → `DataSourceBadge` (আসল `isLoaded` থেকে)
- হার্ডকড `"Live Server Sync Active"` → সত্যিকারের wired-flag গণনা
- "server-wide" টোস্ট → প্রকৃত প্রভাবের সংখ্যা
